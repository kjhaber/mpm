# mpm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `mpm`, a Go CLI/TUI for storing secrets in openssl-encrypted, vicrypt-compatible repository files.

**Architecture:** `cmd/mpm` holds thin cobra wiring; logic lives in `internal/{crypt,vault,config,clip,fuzzy,tui,cli}` behind small interfaces (`Crypter`, `Clipboard`) so tests use fakes. Each repository is one `<root>/<repo>.enc` file: base64 openssl AES-256-CBC (pbkdf2, 100000 iter) over a JSON document.

**Tech Stack:** Go 1.26, cobra, bubbletea/bubbles/lipgloss, system `openssl`, goreleaser, GHA. Reference projects: `~/Projects/current/wn/main` (layout, Makefile, goreleaser, workflows, CLAUDE.md) and `~/Projects/current/tzc`.

**Spec:** `docs/superpowers/specs/2026-11-01-mpm-design.md` (README.md documents the user-facing contract).

## Global Constraints

- Module `github.com/kjhaber/mpm`; Go 1.26; `CGO_ENABLED=0` builds for darwin/linux, amd64/arm64.
- Encryption is only ever `openssl enc -aes-256-cbc -a -salt -pbkdf2 -iter 100000`; password via `-pass fd:3` extra pipe, never argv/env of the child. No custom crypto.
- Flags consistent everywhere: `--repo --secret --field --attrib --value --format`; `ls`/`rm` aliases; hidden aliases `--name` are NOT required (README no longer documents them).
- Paths: settings `$XDG_CONFIG_HOME/mpm/settings.json`, repos `$XDG_DATA_HOME/mpm` (override `MPM_ROOT`), state `$XDG_STATE_HOME/mpm/state.json`. Precedence: flag > env (`MPM_ROOT`, `MPM_FORMAT`, `MPM_REPO`) > settings.json > default. `MPM_PASSWORD` supplies passwords.
- Field attribs: `required` ("true"/"false", default false), `pattern` (RE2, default `.+`).
- Format `text` (default) or `json`. Errors to stderr, non-zero exit.
- Build output only under `build/`; `make all` (fmt, lint, test, build) must pass before any task is called done. Red/green TDD; commit per task.
- Temp files holding plaintext: `0600` inside a `0700` dir, removed on exit and on signals.

## Review Focus

- Wrong password / corrupt ciphertext: `ErrBadPassword`, file untouched (Task 2, 4).
- File changed on disk between load and save: save refused, no data loss (Task 4).
- Values containing `,` `:` `\` or newlines in `--value` (Task 7).
- Empty repo dir / repo name with `/` or `..`: rejected, no path traversal (Task 4).
- Editor exits non-zero or temp file deleted: secret unchanged, temp file removed (Task 9).

### Task 4: internal/vault

**Files:** Create `internal/vault/vault.go`, `field.go`, `store.go`, and `_test.go` for each.

**Interfaces:**
- Consumes: `crypt.Crypter`, `crypt.ErrBadPassword`.
- Produces:
  ```go
  type Field struct { Name string; Required bool; Pattern string }
  type Repo struct { Fields []Field; Secrets map[string]map[string]string }
  func (r *Repo) AddField(name string) error        // error if exists or invalid name; new field optional unless set later
  func (r *Repo) SetAttrib(field, attrib, value string) error // refuses required=true on a repo with secrets? see rule below
  func (r *Repo) GetAttrib(field, attrib string) (string, error)
  func (r *Repo) DeleteAttrib(field, attrib string) error     // resets to default
  func (r *Repo) DeleteField(name string) error
  func (r *Repo) SetSecret(name string, values map[string]string) error // validates required/pattern, unknown field error
  func (r *Repo) DeleteSecret(name string) error
  type Store struct { Root string; Crypter crypt.Crypter }
  func (s *Store) List() ([]string, error)
  func (s *Store) Create(name, password string) error
  func (s *Store) Open(name, password string) (*Handle, error)
  func (s *Store) Delete(name, password string) error // ErrRepoNotEmpty if secrets
  func (s *Store) Copy(from, fromPw, to, toPw string, includeSecrets bool) error

  var ErrRepoNotEmpty, ErrChangedOnDisk, ErrExists, ErrNotFound error
  ```
